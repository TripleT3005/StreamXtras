# Changelog

All notable changes to StreamXtras, grouped by version in the style of [Keep a Changelog](https://keepachangelog.com/). The section of each version is used as its release notes.

Alle wichtigen Änderungen an StreamXtras, gegliedert nach Version im Stil von [Keep a Changelog](https://keepachangelog.com/de/). Der Abschnitt einer Version wird als ihre Release-Notizen verwendet.

## [1.1.1] – 2026-10-31

### English

#### Changed
- The installer no longer creates a desktop shortcut by default.

#### Fixed
- The last page of the installer offers to start StreamXtras instead of promising to open the settings, which only happens on the first start.

### Deutsch

#### Geändert
- Der Installer legt standardmäßig keine Desktop-Verknüpfung mehr an.

#### Behoben
- Die letzte Seite des Installers bietet an, StreamXtras zu starten, statt das Öffnen der Einstellungen zu versprechen, was nur beim ersten Start passiert.

## [1.1.0] – 2026-10-31

### English

#### Added
- Windows installer: installs for the current user without administrator rights or for all users, with Start menu entry, desktop shortcut and optional start with Windows; silent installation with parameters.
- The Windows program declares per-monitor DPI awareness.

#### Changed
- The Windows archive is now named `…-windows-x64-portable.zip`; the release also contains the changelog.

### Deutsch

#### Neu
- Windows-Installer: installiert für den aktuellen Benutzer ohne Administratorrechte oder für alle Benutzer, mit Startmenü-Eintrag, Desktop-Verknüpfung und optionalem Start mit Windows; stille Installation per Parameter.
- Das Windows-Programm meldet Per-Monitor-DPI-Unterstützung.

#### Geändert
- Das Windows-Archiv heißt jetzt `…-windows-x64-portable.zip`; das Release enthält zusätzlich den Changelog.

## [1.0.1] – 2026-10-26

### English

#### Changed
- The included explosion image is now a cartoon explosion with an outline.

### Deutsch

#### Geändert
- Das mitgelieferte Explosionsbild ist jetzt eine Cartoon-Explosion mit Kontur.

## [1.0.0] – 2026-10-26

### English

#### Added
- Ten included images (heart, star, sparkles, StreamXtras X, crown, gift, explosion, rocket, trophy, confetti) and ten included sounds (chime, pop, bell, coin, level up, fanfare, sparkle, whoosh, bubble, drum hit).
- KofiStreamBot and StreamStickers in the list of bots the chat box can hide.
- When you are logged in and no channel is set for the chat box or the top emotes, the settings page fills in your own channel.

#### Changed
- New default image and sound for subscriptions, gift subs, cheers and raids.
- StreamXtras 1.0.0 is the first regular release; earlier versions were pre-releases.

### Deutsch

#### Neu
- Zehn mitgelieferte Bilder (Herz, Stern, Funkeln, StreamXtras-X, Krone, Geschenk, Explosion, Rakete, Pokal, Konfetti) und zehn mitgelieferte Sounds (Chime, Pop, Bell, Coin, Level up, Fanfare, Sparkle, Whoosh, Bubble, Drum hit).
- KofiStreamBot und StreamStickers in der Liste der Bots, die die Chatbox ausblenden kann.
- Bist du angemeldet und ist für die Chatbox oder die Top-Emotes kein Kanal eingetragen, trägt die Einstellungsseite deinen eigenen Kanal ein.

#### Geändert
- Neues Standardbild und neuer Standardsound für Abos, Geschenkabos, Cheers und Raids.
- StreamXtras 1.0.0 ist das erste reguläre Release; frühere Versionen waren Vorabversionen.

## [0.6.0] – 2026-10-26

### English

#### Added
- Chat box filters: hide messages from chosen bots, from the streamer, from further accounts you enter and messages with blocked words.
- Back link on the diagnostics page.

#### Changed
- Release archives and the program file are named StreamXtras (on Linux the program stays `streamxtras`).
- The settings page and the included heart and sparkles images use the StreamXtras violet instead of Twitch's purple.

### Deutsch

#### Neu
- Chatbox-Filter: Nachrichten von gewählten Bots, vom Streamer, von weiteren eingetragenen Konten und Nachrichten mit gesperrten Wörtern ausblenden.
- Zurück-Link auf der Diagnoseseite.

#### Geändert
- Release-Archive und Programmdatei heißen StreamXtras (unter Linux bleibt das Programm `streamxtras`).
- Die Einstellungsseite und die mitgelieferten Bilder Herz und Funkeln nutzen das StreamXtras-Violett statt des Twitch-Lilas.

## [0.5.0] – 2026-10-26

### English

#### Added
- The settings page shows a link when a newer version is available on GitHub (checked at most once a day).
- Live control of all alert boxes: replay the last alert, skip the current alert, pause and resume alerts, with a banner on every tab while paused.
- Goals can use the active goal from your Twitch creator dashboard, updated live. Log in again once so that StreamXtras may read your goals.

### Deutsch

#### Neu
- Die Einstellungsseite zeigt einen Link, wenn auf GitHub eine neuere Version verfügbar ist (höchstens einmal am Tag geprüft).
- Live-Steuerung aller Alertboxen: letzten Alert wiederholen, aktuellen Alert überspringen, Alerts pausieren und fortsetzen, mit Banner auf jedem Tab während der Pause.
- Ziele können das aktive Ziel aus deinem Twitch-Creator-Dashboard nutzen, live aktualisiert. Melde dich einmal neu an, damit StreamXtras deine Ziele lesen darf.

## [0.3.0] – 2026-10-26

### English

#### Added
- Alerts for subscriptions, gift subs, cheers and raids in addition to follows, each with its own text, image or video, sound and duration.
- Variants per alert type, e.g. for an exact number of bits, from a number on, a subscription tier or a certain Twitch user.
- Profile picture of the user instead of the image, e.g. for raids.
- Video clips (MP4, WebM) as alert image; uploads up to 50 MB.
- Text-to-speech with the voices of the operating system, per alert type with minimums and tiers.
- Placeholders `{message}` and `{tier}` in alert texts.
- `?types=` in the alert box URL shows only the chosen alert types.

#### Changed
- Subscription tiers and Prime come from Twitch's chat notifications. Log in again once after updating.

#### Security
- The media selection on the settings page only accepts known files.

### Deutsch

#### Neu
- Alerts für Abos, Geschenkabos, Cheers und Raids zusätzlich zu Follows, jeweils mit eigenem Text, Bild oder Video, Sound und Dauer.
- Varianten je Alert-Typ, z. B. für eine genaue Zahl an Bits, ab einer Zahl, eine Abo-Stufe oder einen bestimmten Twitch-Nutzer.
- Profilbild des Nutzers statt des Bildes, z. B. bei Raids.
- Video-Clips (MP4, WebM) als Alert-Bild; Uploads bis 50 MB.
- Sprachausgabe mit den Stimmen des Betriebssystems, je Alert-Typ mit Mindestwerten und Stufen.
- Platzhalter `{message}` und `{tier}` in Alert-Texten.
- `?types=` in der Adresse der Alertbox zeigt nur die gewählten Alert-Typen.

#### Geändert
- Abo-Stufen und Prime kommen aus Twitchs Chat-Benachrichtigungen. Nach dem Update einmal neu anmelden.

#### Sicherheit
- Die Medienauswahl der Einstellungsseite nimmt nur bekannte Dateien an.

## [0.2.1] – 2026-10-25

### English

#### Changed
- The settings page has tabs for each overlay and a compact header with the Twitch login.

#### Fixed
- The browser is opened through Windows itself instead of `rundll32`, which some virus scanners reported.

### Deutsch

#### Geändert
- Die Einstellungsseite hat Tabs für jedes Overlay und einen kompakten Kopf mit dem Twitch-Login.

#### Behoben
- Der Browser wird über Windows selbst geöffnet statt über `rundll32`, was einige Virenscanner gemeldet hatten.

### Deutsch
