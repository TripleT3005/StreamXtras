## English

All translations were generated by Claude (AI). Files that a person has checked name the reviewer in the table and in the file itself. If you notice a mistake or know a better wording, please open an [issue](https://github.com/TripleT3005/StreamXtras/issues) or a pull request; reviewers are credited with their GitHub name if they agree.

The codes follow [BCP 47](https://www.rfc-editor.org/info/bcp47): ISO 639 language codes, ISO 3166 regions and ISO 15924 scripts. Dialects use their ISO 639-3 code where one exists, everything else a private-use code with `-x-`. Dialects and fun languages are only offered in the language selection of the settings page, never chosen automatically. Missing texts fall back to German for the German dialects and to English otherwise.

This list is generated from the headers of the files in [`web/lang`](web/lang). After changing them, run `$env:UPDATE_LANGUAGES = 1; cargo test language_list` in `companion` to update it; the CI fails if it is out of date.

## Deutsch

Alle Übersetzungen wurden von Claude (KI) erzeugt. Dateien, die eine Person geprüft hat, nennen die prüfende Person in der Tabelle und in der Datei selbst. Wenn dir ein Fehler auffällt oder du eine bessere Formulierung kennst, eröffne gern ein [Issue](https://github.com/TripleT3005/StreamXtras/issues) oder einen Pull Request; mit Einverständnis wird die prüfende Person mit ihrem GitHub-Namen genannt.

Die Codes folgen [BCP 47](https://www.rfc-editor.org/info/bcp47): ISO-639-Sprachcodes, ISO-3166-Regionen und ISO-15924-Schriften. Dialekte nutzen ihren ISO-639-3-Code, sofern es einen gibt, alles andere einen Private-Use-Code mit `-x-`. Dialekte und Spaßsprachen werden nur in der Sprachauswahl der Einstellungsseite angeboten, nie automatisch gewählt. Fehlende Texte fallen bei den deutschen Dialekten auf Deutsch zurück, sonst auf Englisch.

Diese Liste wird aus den Köpfen der Dateien in [`web/lang`](web/lang) erzeugt. Nach Änderungen daran aktualisiert `$env:UPDATE_LANGUAGES = 1; cargo test language_list` in `companion` sie; die CI schlägt fehl, wenn sie veraltet ist.
